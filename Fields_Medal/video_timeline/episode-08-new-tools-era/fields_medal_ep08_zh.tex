% ========== SCHOLZE ==========
\newcommand{\scholzeslide}{%
\personslide
  {Peter Scholze}
  {彼得·朔尔策：Perfectoid 空间、p-adic Hodge}
  {images/peter_scholze.jpg}
  {Photo: Wikipedia}
  {2018（30岁）}
  {1987–}
  {德国}
  {University of Bonn / Max Planck Institute}
  {Scholze 提出 Perfectoid 空间，为 p-adic 几何与 p-adic Hodge 理论提供了革命性的新框架，极大简化并推进了 Langlands 纲领中的一系列结果。这套语言已成为算术几何的通用工具，重塑了整个领域的研究方式。\\[3pt]
  \textbf{一句话：} 他造出的 Perfectoid 空间，如今是算术几何学家人手一件的基本工具。}
}

% ========== BIRKAR ==========

  {Photo: Wikipedia}
  {2018（40岁）}
  {1978–}
  {伊朗/英国}

  {Birkar 在双有理代数几何的极小模型纲领上取得重大进展，证明了 Fano 簇的有界性（BAB 猜想），为高维簇的分类奠定基础。他早年作为库尔德难民从伊朗来到英国，其经历成为这一届的传奇。\\[3pt]
  \textbf{一句话：} 他证明了一大类几何空间"本质上只有有限多种"，让分类成为可能。}
}
