# 《现代数学九十年》— 菲尔兹奖时间线纪录片系列

> **定位**：以时间线为主轴的纪录片式系列，与按学科分类的 13 集主系列互为补充。
>
> - **主系列**（`video/`）：13 集按学科分类 → 人物百科，方便按兴趣检索
> - **时间线系列**（`video_timeline/`）：第零集 + 九集正片（共 10 集）→ 叙事纪录片，展现数学思想的连续演进

---

## 为什么按时间线？

**这条系列不是在回答"今年谁获奖了"，而是在回答"数学为什么会发展成今天这样"。**

```
第零集  什么是菲尔兹奖？

第一集  1936–1958   分析学 → 法国学派建立现代语言
                    ↓
第二集  1962–1970   现代数学革命：Scheme / Forcing / K Theory / h-cobordism
                    ↓
第三集  1974–1982   几何统一数学
                    ↓
第四集  1986        四维革命（Donaldson / Freedman / Faltings）
                    ↓
第五集  1990–1998   数学大融合：几何 × 物理 × 表示论 × 拓扑 × 范畴
                    ↓
第六集  2002–2006   Perelman 高潮：Ricci flow 完成几何化纲领
                    ↓
第七集  2010        现代数学四大前沿：Langlands / 最优传输 / 概率 / 遍历论
                    ↓
第八集  2014–2018   新工具时代：Perfectoid / 正则性结构 / BAB
                    ↓
第九集  2022–2026   最新前沿 → 下一场革命会来自哪里？
```

**最大的优点：每一集之间都有因果联系，而不是各自孤立地讲"今年谁获奖了"。** 观众看到的是数学从一个时代自然生长到下一个时代。

## 第零集：什么是菲尔兹奖

**主题**：在开始讲述人物之前，先回答观众真正关心的问题。

### 内容

| 问题 | 要点 |
|------|------|
| 为什么只有 40 岁以下？ | Fields 的遗愿：鼓励未来，而非回顾过去 |
| 为什么四年一次？ | 配合国际数学家大会（ICM）的节奏 |
| 为什么没有诺贝尔数学奖？ | 流传的传闻与历史真相 |
| John Charles Fields 是谁？ | 一位加拿大数学家的远见 |
| 为什么奖牌上没有名字？ | 致敬阿基米德 — 奖牌背面刻着他的名言 |
| 为什么奖金只有一万多美元？ | 荣誉远大于金钱 |
| 为什么 Grothendieck 拒绝？ | 政治抗议：1966 年莫斯科 ICM 上的缺席 |
| 为什么 Perelman 拒绝？ | "我不需要这个奖。" |
| 为什么 Witten 可以拿？ | 物理学家也可以是数学家 |
| 为什么有人终身没有拿？ | Erdős、Shannon、Nash…… |

### 叙事线

- 意外性：奖牌本身的故事比获奖者的故事更少人知道
- 悬念：为什么这个奖如此特别？
- 过渡：引出九集正片 — 接下来你将看到的，是 90 年来数学最精彩的故事

### 收束

> 菲尔兹奖不是终点，而是数学历史的路标。读懂这些路标，你就读懂了现代数学的灵魂。

## 第一集：战前与法国学派的诞生（1936–1958）

**主题**：现代数学语言正在形成。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Lars Ahlfors | 1936 | 黎曼曲面、拟共形映射 |
| Jesse Douglas | 1936 | 极小曲面、Plateau 问题 |
| Laurent Schwartz | 1950 | 分布理论、泛函分析 |
| Atle Selberg | 1950 | 素数定理初等证明、Selberg 筛法 |
| Jean-Pierre Serre | 1954 | 代数拓扑、层论、Hodge 理论 |
| Kunihiko Kodaira | 1954 | 复流形、Hodge–Kodaira 理论 |
| Klaus Roth | 1958 | 丢番图逼近 |
| René Thom | 1958 | 配边理论、奇点理论 |

### 叙事线

- 1936：菲尔兹奖诞生，两位获奖者分别代表复分析与变分法
- 1950：战后重启，法国学派崛起（Schwartz → Bourbaki 精神）
- 1954：Serre 与 Kodaira 标志着代数几何与复几何的现代化
- 1958：Thom 的配边理论为拓扑革命埋下伏笔

### 收束

> Bourbaki 重建了数学的语言，而这一代人用这门新语言写出了第一批杰作。

## 第二集：现代数学革命（1962–1970）

**主题**：不是某一个方向的革命，而是现代数学基础设施的全面建立。今天几乎所有数学工具都诞生于这十年。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| John Milnor | 1962 | 奇异球面 (exotic sphere)、微分拓扑 |
| Lars Hörmander | 1962 | 线性偏微分算子 |
| Stephen Smale | 1966 | h-cobordism、高维庞加莱猜想 |
| Alexander Grothendieck | 1966 | Scheme、Topos、Étale 上同调 |
| Paul Cohen | 1966 | Forcing、连续统假设独立性 |
| Michael Atiyah | 1966 | K 理论、Atiyah–Singer 指标定理 |
| Sergei Novikov | 1970 | 拓扑不变量、Novikov 猜想 |
| John G. Thompson | 1970 | 有限群论、奇阶定理 |
| Heisuke Hironaka | 1970 | 奇点消解 |
| Alan Baker | 1970 | 超越数论、线性形式 |

### 叙事线

- 1962：Milnor 的奇异球面打开微分拓扑，Hörmander 统一 PDE 理论
- 1966：**史上最传奇的一届** — Grothendieck 重写代数几何，Atiyah 连接拓扑与分析，Cohen 解决集合论独立性，Smale 解决高维庞加莱猜想
- 1970：Hironaka 完成奇点消解，Thompson 推动有限群分类，Novikov 建立拓扑不变量

### 收束

> 这不是"拓扑革命" — Grothendieck 的不是拓扑，Cohen 的不是拓扑，Atiyah 的也不仅仅是拓扑。正确的问题是：**现代数学的基础设施** — Scheme、Forcing、K 理论、h-cobordism、奇异球面、奇点消解 — 全部在这十年建成。1966 年是数学的奇迹年。

## 第三集：几何成为数学的新语言（1974–1982）

**主题**：几何不再是数学的一个分支，而是数学的统一语言。Mumford、Deligne、Yau、Thurston、Connes — 全部都在做"几何化"。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Enrico Bombieri | 1974 | 解析数论、极小曲面 |
| David Mumford | 1974 | 几何不变量理论、模空间 |
| Pierre Deligne | 1978 | Weil 猜想、Hodge 理论 |
| Charles Fefferman | 1978 | 调和分析、多复变 |
| Grigory Margulis | 1978 | Lie 群格、超刚性 |
| Daniel Quillen | 1978 | 高阶代数 K 理论 |
| Alain Connes | 1982 | 非交换几何、算子代数 |
| William Thurston | 1982 | 三维几何化纲领 |
| Shing-Tung Yau | 1982 | Calabi 猜想、几何分析 |

### 叙事线

- 1974：Mumford 的模空间与 Bombieri 的解析方法，代数几何走向成熟
- 1978：Deligne 完成 Weil 猜想（Grothendieck 纲领的巅峰），Margulis 用遍历论解决数论问题，Quillen 建立 K 理论
- 1982：三位巨人同时获奖 — Connes（算子代数）、Thurston（三维流形）、Yau（微分几何），几何从三个方向统一数学

### 收束

> 这一集的核心词只有一个：**几何化**。Mumford 用几何研究代数，Deligne 用几何研究数论，Yau 用几何研究物理，Thurston 用几何研究拓扑，Connes 用几何研究算子代数。几何成为了数学的通用语法。

---

## 第四集：四维革命（1986）

**主题**：一个特殊年份，三个最重要方向同时爆发。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Simon Donaldson | 1986 | 四维流形、规范理论 |
| Michael Freedman | 1986 | 四维拓扑庞加莱猜想 |
| Gerd Faltings | 1986 | Mordell 猜想、算术几何 |

### 叙事线

- Freedman 证明拓扑四维庞加莱猜想 → 四维拓扑分类
- Donaldson 用 Yang–Mills 规范理论发现四维流形的奇异性 → 物理学入侵数学
- Faltings 证明 Mordell 猜想 → 算术几何的里程碑
- 预告：Witten 时代即将开始

### 收束

> 四维是拓扑最奇特的维数。1986 年，三位数学家从三个方向同时揭示了这个维度的秘密 — 而物理学家 Witten 正在门外等待。

---

## 第五集：数学大融合（1990–1998）

**主题**：数学史上最丰富的十年，所有方向开始交汇。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Vaughan Jones | 1990 | Jones 多项式、纽结不变量 |
| Edward Witten | 1990 | 拓扑量子场论、弦理论 |
| Vladimir Drinfeld | 1990 | 量子群、Langlands |
| Shigefumi Mori | 1990 | 极小模型纲领 |
| Jean Bourgain | 1994 | Banach 空间、调和分析 |
| Pierre-Louis Lions | 1994 | 非线性 PDE、平均场博弈 |
| Efim Zelmanov | 1994 | 受限 Burnside 问题 |
| Jean-Christophe Yoccoz | 1994 | 动力系统、小除数 |
| Timothy Gowers | 1998 | Banach 空间、组合数论 |
| Curtis McMullen | 1998 | 复动力系统、双曲几何 |
| Maxim Kontsevich | 1998 | 形变量子化、镜像对称 |
| Richard Borcherds | 1998 | 顶点代数、怪兽月光 |

### 叙事线

- 1990：Witten 获奖标志着数学物理正式进入主流；Jones 和 Drinfeld 从不同方向连接拓扑与代数
- 1994：四位获奖者分别代表分析、PDE、代数、动力系统 — 数学的广度达到顶峰
- 1998：Kontsevich 的形变量子化、Borcherds 的月光猜想 — 数学与物理的边界彻底模糊

### 收束

> 当 Witten 以物理学家身份获得菲尔兹奖时，数学与物理之间的墙倒塌了。此后十年，量子群、镜像对称、月光猜想 — 数学不再有边界。

---

## 第六集：进入 21 世纪（2002–2006）

**主题**：新世纪的数学以 Perelman 为高潮。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Laurent Lafforgue | 2002 | Langlands 纲领（函数域） |
| Vladimir Voevodsky | 2002 | 动机上同调、Milnor 猜想 |
| Terence Tao | 2006 | 素数算术级数、调和分析 |
| Grigori Perelman | 2006 | Ricci flow、庞加莱猜想（拒绝领奖） |
| Wendelin Werner | 2006 | SLE、共形不变性 |
| Andrei Okounkov | 2006 | 随机矩阵、枚举几何 |

### 叙事线

- 2002：Lafforgue 推进 Langlands，Voevodsky 实现 Grothendieck 的动机梦想
- 2006：**Perelman 解决庞加莱猜想并拒绝领奖** — 数学史上最戏剧性的时刻
- Tao 以 31 岁成为最年轻获奖者之一，代表"全能型"数学家的回归
- Werner 和 Okounkov 标志着概率论与组合学的崛起

### 收束

> Perelman 用 Ricci flow 完成了 Thurston 的几何化纲领 — 然后消失了。但他留下的不只是一个定理，而是一个信号：几何分析的时代已经到来。

---

## 第七集：现代数学四大前沿（2010）

**主题**：今天数学已经没有唯一中心。Langlands、最优传输、概率、遍历论 — 四个方向同时站在最前沿，告诉观众：现代数学是多中心的。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Ngô Bảo Châu | 2010 | 基本引理、Langlands 纲领 |
| Cédric Villani | 2010 | 最优传输、Boltzmann 方程 |
| Stanislav Smirnov | 2010 | 渗流、共形不变性 |
| Elon Lindenstrauss | 2010 | 遍历论、丢番图逼近 |

### 叙事线

- Ngô 证明基本引理 → Langlands 纲领的关键一步
- Villani 发展最优传输理论 → PDE 与几何的新桥梁
- Smirnov 证明渗流的共形不变性 → 概率论的严格化
- Lindenstrauss 用遍历论解决数论问题 → 动力系统方法的胜利

### 收束

> 这一集在告诉观众：**今天数学已经没有唯一中心。** Ngô 代表 Langlands 纲领，Villani 代表最优传输与 PDE，Smirnov 代表概率论的严格化，Lindenstrauss 代表遍历论与数论的交汇。四座山峰，同时耸立。

---

## 第八集：新工具时代（2014–2018）

**主题**：这一代人的标志不是年轻，而是创造了全新的数学工具。Perfectoid 空间、正则性结构、BAB 猜想、算术统计 — 这些工具将定义未来二十年的数学。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Maryam Mirzakhani | 2014 | 双曲曲面、Teichmüller 动力学 |
| Manjul Bhargava | 2014 | 高阶合成律、算术统计 |
| Artur Avila | 2014 | 动力系统、谱理论 |
| Martin Hairer | 2014 | 正则性结构、随机 PDE |
| Alessio Figalli | 2018 | 最优传输、Monge–Ampère |
| Peter Scholze | 2018 | Perfectoid 空间、p-adic Hodge |
| Caucher Birkar | 2018 | 极小模型纲领、BAB 猜想 |
| Akshay Venkatesh | 2018 | 解析数论、自守形式 |

### 叙事线

- 2014：Mirzakhani 成为首位女性获奖者；Hairer 创造正则性结构解决随机 PDE
- 2018：Scholze 的 perfectoid 空间重塑 p-adic 几何；Birkar 推进极小模型纲领
- 这一代人的共同特点：不是年轻，而是创造了新工具 — Perfectoid、正则性结构、BAB、算术统计

### 收束

> Mirzakhani 证明了数学没有性别。Scholze 创造了 Perfectoid 空间 — 这不是"26 岁天才"的故事，而是一个新工具如何重塑 p-adic 几何的故事。Hairer 的正则性结构让随机 PDE 第一次有了严格基础。这一集的关键词不是"年轻"，而是**新工具**。

## 第九集：最新前沿（2022–2026）

**主题**：今天数学最热门的方向，以及未来的展望。

### 人物

| 姓名 | 获奖年 | 关键词 |
|------|--------|--------|
| Maryna Viazovska | 2022 | 球填充、模形式 |
| Hugo Duminil-Copin | 2022 | 渗流、相变 |
| James Maynard | 2022 | 素数间隙 |
| June Huh | 2022 | 组合代数几何、Hodge 理论 |
| Yu Deng | 2026 | Boltzmann 方程、希尔伯特第六问题 |
| Hong Wang | 2026 | Kakeya 猜想、调和分析 |
| John Pardon | 2026 | 辛几何、虚基本类 |
| Jacob Tsimerman | 2026 | André–Oort 猜想、O-minimality |

### 叙事线

- 2022：Viazovska 用模形式解决 8 维球填充；Huh 把代数几何引入组合学
- 2026：Yu Deng 推进希尔伯特第六问题；Hong Wang 解决 Kakeya 猜想
- 回顾：90 年来的故事线 — 从分析学到现代语言，从革命到融合，从统一到新工具

### 收束（开放结尾）

> 从 1936 年 Ahlfors 的黎曼曲面，到 2026 年 Deng 的 Boltzmann 方程 — 九十年间，数学从未停止生长。每一代人都在前人的肩膀上，看到更远的风景。
>
> **下一场革命会来自哪里？**
