# 沃尔夫数学奖人物专题分类

用途：作为后续制作 PPT/视频课件的分集结构。原则是**除第 1 集为导论/综述集外，每集围绕一个数学主题展开**；人物页保持“一页只放一位数学家”。本文件只列沃尔夫数学奖得主，其他数学奖项人物不混入本专题。

> 分类轴说明（2026-07 修订）：为保持分类轴统一，第 1 集不再独占“首届四人”，而是作为**纯导论集**（讲奖项定位、评价标准与整体地图）。首届得主 Gelfand、Siegel、Leray、Weil 的正式人物页按主题下放：Leray、Weil → 第 2 集，Siegel → 第 8 集，Gelfand → 第 12 集。第 1 集可在综述中提及他们，但不作为其最终主题归属。

## 推荐分集结构

| 集数 | 主题 | 沃尔夫数学奖得主代表人物 | 分类说明 |
|---:|---|---|---|
| 第1集 | 导论：沃尔夫数学奖的定位与百年数学地图 | （导论集，无独占人物页；综述式提及首届四人与各主题代表） | 讲奖项起源、无年龄限制、侧重终身贡献，与菲尔兹奖/阿贝尔奖的差异，并概览后续 11 个主题分集。 |
| 第2集 | Bourbaki、同调与代数几何基础 | Jean Leray、André Weil、Henri Cartan、Oscar Zariski、Samuel Eilenberg、Jean-Pierre Serre、Michael Artin | 讲层与谱序列、Bourbaki、同调代数、范畴论、交换代数、代数几何基础和现代数学语言的重建。 |
| 第3集 | 复分析、调和分析与 PDE | Lars Ahlfors、Hans Lewy、Lars Hörmander、Alberto Calderón、Elias M. Stein、Charles Fefferman、Lennart Carleson | 覆盖复分析、偏微分方程、微局部分析、奇异积分、调和分析、多复变和 Fourier 级数收敛。 |
| 第4集 | 应用数学、自由边界与小波 | Peter Lax、Joseph B. Keller、Luis Caffarelli、Ingrid Daubechies | 从应用数学和渐近方法讲到非线性 PDE、自由边界、最优传输、小波和信号处理。 |
| 第5集 | 概率、随机过程与随机几何 | Andrey Kolmogorov、Kiyoshi Itō、Jean-François Le Gall、Gregory Lawler | 从概率论公理化、随机微积分到布朗运动、SLE 和随机几何。 |
| 第6集 | 拓扑革命 | Hassler Whitney、Friedrich Hirzebruch、John Milnor、Raoul Bott、Dennis Sullivan、Sergei Novikov、Stephen Smale、Simon Donaldson | 讲微分拓扑、K 理论、Bott 周期性、有理同伦、四维流形、规范理论和庞加莱猜想相关主线。 |
| 第7集 | 微分几何、几何分析与辛几何 | Shiing-Shen Chern、Ennio De Giorgi、Mikhail Gromov、Shing-Tung Yau、George Mostow、Richard Schoen、Yakov Eliashberg | 覆盖陈类、极小曲面、黎曼几何、几何分析、刚性定理、辛几何和接触几何。 |
| 第8集 | 数论、自守形式与 Langlands | Carl Ludwig Siegel、Atle Selberg、Ilya Piatetski-Shapiro、Robert Langlands、Andrew Wiles、John Tate、Peter Sarnak、James Arthur | 从古典数论与 Siegel 定理，到 Selberg 迹公式、自守形式、L 函数、Langlands 纲领、费马大定理和 Arthur-Selberg 迹公式。 |
| 第9集 | 代数几何、Hodge 理论与表示论 | Kunihiko Kodaira、Pierre Deligne、Phillip Griffiths、David Mumford、Mikio Sato、Alexander Beilinson、Vladimir Drinfeld、George Lusztig | 讲复几何、Hodge 理论、Weil 猜想、模空间、代数分析、D 模、量子群和代数群表示论。 |
| 第10集 | 群论、组合数学与计算 | Paul Erdős、John G. Thompson、Jacques Tits、Michael Aschbacher、László Lovász、Noga Alon、Adi Shamir | 覆盖组合数学、有限群分类、建筑理论、图论、组合优化、密码学和理论计算。 |
| 第11集 | 动力系统与遍历理论 | Jürgen Moser、Vladimir Arnold、Yakov Sinai、Hillel Furstenberg、Grigory Margulis | 讲 KAM 理论、经典力学、混沌、遍历理论、测度刚性、Lie 群格和动力系统方法。 |
| 第12集 | 泛函分析、算子理论与数理逻辑 | Israel Gelfand、Mark Krein、Saharon Shelah | 讲泛函分析与表示论的奠基（Gelfand）、算子理论、矩问题、逆散射，以及模型论、集合论和数理逻辑。 |

## 覆盖口径

- 第 1 集为导论集，不独占人物页；第 2–12 集为主题集，覆盖 `68` 位沃尔夫数学奖得主，每位得主只在一个主题集出现一次。
- 首届四人的主题归属：Leray、Weil → 第 2 集，Siegel → 第 8 集，Gelfand → 第 12 集。第 1 集导论可综述式提及，不重复计入。
- “菲尔兹奖+沃尔夫奖双料得主”“女性得主”“华人得主”“2020 年代近年得主”适合作为专题页，不放进主题集重复列人。
- 跨领域人物按本课件最适合讲述的主线归类；例如 Jean-Pierre Serre 放在现代数学语言与代数几何基础，Vladimir Drinfeld 放在代数几何与表示论，Grigory Margulis 放在动力系统与遍历理论。

## 每位数学家页面建议字段

| 字段 | 用途 |
|---|---|
| 集数与主题 | 标明该人物属于哪一集。 |
| 获奖年份 | 如 `1978`、`1983/84`、`2024`。 |
| 英文姓名 | Wikipedia 标准姓名。 |
| 中文名 | 有通行中文名则补充，如陈省身、丘成桐、伊藤清。 |
| 生卒年 | 如 `1926-`、`1913-2009`。 |
| 国籍/身份 | 可保留多重身份或迁移背景。 |
| 获奖时机构 | 获奖时任职大学或研究机构。 |
| 主要领域 | 用 2-4 个关键词概括。 |
| 核心成就 | 用 1-2 句中文说明获奖贡献。 |
| 代表关键词 | 如 `Langlands 纲领`、`Itô calculus`、`Chern class`。 |
| 与其他大奖关系 | 是否也是菲尔兹奖、阿贝尔奖、图灵奖等得主。 |
| 图片路径 | 指向 `Wolf_Prize/pages/<年份>/<姓名>/images/` 中的头像或相关图片。 |
| Wikipedia 本地页面 | 指向 `Wolf_Prize/pages/<年份>/<姓名>/index.html`。 |

## 课件结构建议

1. 封面：沃尔夫数学奖人物谱系。
2. 总览：奖项起源、无年龄限制、与菲尔兹奖/阿贝尔奖的差异。
3. 分集目录：列出 12 集主题和代表人物。
4. 每集开场页：主题、时代背景、数学主线、代表人物。
5. 人物页：每页一位数学家。
6. 专题页：女性得主、菲尔兹+沃尔夫双料得主、华人得主、2020 年代近年得主、未颁发年份。
7. 结尾页：从沃尔夫奖看 20 世纪数学主干。
