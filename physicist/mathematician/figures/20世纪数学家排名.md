# 20世纪数学家排名 (Top 100)

> 排名根据狄多涅的《纯粹数学全貌》、岩波数学百科全书、苏联出版的数学百科全书综合量化分析得出。

| 排名 | 姓名 | 简介 |
|:---:|------|------|
| 1 | **A.N. Kolmogorov** (柯尔莫哥洛夫) | 为概率论建立了公理体系的俄罗斯数学家。但排第一似乎有些不妥？ |
| 2 | **H. Poincaré** (庞加莱) | 有些人不需要说明，庞加莱就是其中之一。 |
| 3 | **D. Hilbert** (希尔伯特) | 号称数学之王，无数天才的老师，20世纪最后一位数学全才。 |
| 4 | **A.E. Noether** (诺特) | 二十世纪代数学执牛耳者，诺特阿姨，史上少有的数学女王。 |
| 5 | **Von Neumann** (冯·诺依曼) | 计算机的发明者，传说他思考数学问题的速度和计算机一样快。 |
| 6 | **H. Weyl** (外尔) | Weyl曲率张量，是Riemann曲率张量的零迹部分，描述物体沿测地线运动的潮汐力。 |
| 7 | **A. Weil** (韦伊) | 布尔巴基学派的精神领袖。Weil猜想揭示了定义于有限域上代数簇的算术性质同定义于复数域上代数簇的拓扑性质之间的深刻联系，是20世纪气势恢弘的猜想。 |
| 8 | **I.M. Gelfand** (盖尔范德) | 首届Wolf奖得主，泛函分析大师。他解决了Hilbert关于超越数的问题。 |
| 9 | **Wiener** (维纳) | 典型的神童，控制论的创立人。 |
| 10 | **Alexandroff** (亚历山德罗夫) | 点集拓扑中的Alexandroff紧化。 |
| 11 | **Lebesgue** (勒贝格) | 实分析开山鼻祖，勒贝格积分。 |
| 12 | **Shafarevich** (沙法列维奇) | 代数几何、代数数论学家，超强的实力派。 |
| 13 | **V.I. Arnold** (阿诺德) | Kolmogorov最得意的门徒，又一个了不起的俄罗斯人。Arnold猜想。 |
| 14 | **Dedekind** (戴德金) | 著名的戴德金分割，Dedekind环。 |
| 15 | **Markov** (马尔可夫) | 马尔可夫过程。证明了维数大于等于4的拓扑流形的同胚分类是算法不可解的。 |
| 16 | **Klein** (克莱因) | 爱尔兰根纲领（厄兰根纲领），是个天才。 |
| 17 | **E. Artin** (阿廷) | 大代数学家。Artin互反律，数论中最强的互反律。 |
| 18 | **Jordan** (若尔当) | Jordan闭曲线定理。 |
| 19 | **Siegel** (西格尔) | 来自哥廷根，首届Wolf奖得主。 |
| 20 | **Sobolev** (索伯列夫) | Sobolev空间中的嵌入定理是现代PDE的基石。 |
| 21 | **J.P. Serre** (塞尔) | 1954年获Fields奖，时年不足28周岁。 |
| 22 | **Grothendieck** (格罗滕迪克) | 走在时代前面的格罗滕迪克！上帝！神明！ |
| 23 | **Whitney** (惠特尼) | 微分拓扑的开山鼻祖。Whitney嵌入定理，终生对四色定理感兴趣。 |
| 24 | **É. Cartan** (嘉当) | 大器晚成的微分几何大家。流形上的分析是当今极为活跃的数学分支，嘉当是该分支的重要缔造者。 |
| 25 | **Thom** (托姆) | 突变论创立者，Thom配边理论才是他的数学成就。 |
| 26 | **Milnor** (米尔诺) | 与纳什合称普林斯顿那一届的双子星，微分拓扑大师。最早发现主猜想是错的数学家。 |
| 27 | **Hadamard** (阿达玛) | 法国数学家，证明了素数定理。 |
| 28 | **Gödel** (哥德尔) | 哥德尔不完备定理。 |
| 29 | **Landau** (兰道) | 德国数学家，用一种更简单的分析方法证明了高斯提出的素数定理，并应用于代数数域上的素理想分布。 |
| 30 | **Hecke** (赫克) | 赫克代数。 |
| 31 | **陈省身** | 一代宗师，华人的骄傲。陈老先生的文章简约明了。 |
| 32 | **Zermelo** (策梅罗) | ZFC公理系统的参与建立者，这个系统是整个现代数学大厦的地基。 |
| 33 | **Pontryagin** (庞特里亚金) | Pontryagin示性类，最早的示性类。 |
| 34 | **H. Cartan** (小嘉当) | 老嘉当之子，子承父业。 |
| 35 | **Hopf** (霍普夫) | 来自瑞士的拓扑学大师，Harvard大学教授。 |
| 36 | **小平邦彦** | 日本数学家，大器晚成，勤奋的代数几何学家。消灭定理实在很好。 |
