# 欧拉与伯努利家族 — 立传指引

> **一个家族，三代数学家 —— 伯努利家族如何改变数学？**
>
> 欧拉与伯努利家族同属 18 世纪数学的黄金时代，二者关系之深、影响之远，适合放在一起作为系列企划。

---

## 一、人物概览

| 人物 | 生卒 | 核心贡献 | 优先级 |
|------|:--:|------|:--:|
| **Jacob Bernoulli** (雅各布·伯努利) | 1655–1705 | 概率论（大数定律）、伯努利数、微积分 | ⭐⭐⭐⭐⭐ |
| **Johann Bernoulli** (约翰·伯努利) | 1667–1748 | 微积分、微分方程、变分法、欧拉的老师 | ⭐⭐⭐⭐⭐ |
| **Daniel Bernoulli** (丹尼尔·伯努利) | 1700–1782 | 流体力学（伯努利原理）、概率论、数学物理 | ⭐⭐⭐⭐⭐ |

```
 莱布尼茨 (1646–1716)
        │
        ↓
  ┌── Jacob Bernoulli (1655–1705) ── 概率论奠基
  │
  ↓
 Johann Bernoulli (1667–1748) ── 微积分推广、变分法
  │
  ├────→ Nicolaus II (1695–1726)  [早逝]
  ├────→ Daniel Bernoulli (1700–1782) ── 流体力学、概率论
  ├────→ Johann II (1710–1790)
  │         │
  │         └──→ Johann III (1744–1807)
  │
  ↓ (师生关系)
 Euler (1707–1783) ── 18 世纪数学集大成者
```

**关键线索**：
- **Johann Bernoulli → Euler**：欧拉年轻时在巴塞尔师从约翰·伯努利，这层师生关系是 18 世纪数学传承的核心纽带。
- **Daniel Bernoulli 与 Euler 同时代**：两人是圣彼得堡科学院的同事与好友，在流体力学、概率论等领域相互影响。
- **莱布尼茨 → Jacob/Johann Bernoulli**：微积分的早期传播者。

## 四、立传建议顺序

| 顺序 | 人物 | 理由 |
|:--:|------|------|
| 1 | **Euler** | 欧拉是 18 世纪数学的绝对核心，先立欧拉传可建立整个时代的坐标 |
| 2 | **Jacob Bernoulli** | 伯努利家族第一代数学巨匠，概率论的源头 |
| 3 | **Johann Bernoulli** | 欧拉的老师，变分法的创立者 |
| 4 | **Daniel Bernoulli** | 流体力学之父，与欧拉的互动是制作亮点 |

> 建议欧拉先做，因为他的故事自带"18 世纪数学全景图"属性。做完欧拉后，伯努利三人的传记可以自然串联。

## 五、内容线索建议

### Euler 传记高光

- 圣彼得堡 → 柏林 → 圣彼得堡的三段人生
- 失明后的高产（靠心算和助手笔述）
- 欧拉公式 `e^{iπ} + 1 = 0`
- 图论起源：柯尼斯堡七桥问题
- 与腓特烈大帝、叶卡捷琳娜大帝的关系

### Bernoulli 家族传记高光

- 家族内部的竞争（雅各布 vs 约翰的兄弟之争）
- 最速降线问题（brachistochrone）—— 变分法的起点
- 丹尼尔的流体力学与伯努利原理
- 一个家族如何连续四代产出数学家

### 公共线索

- **最速降线问题**：Johann Bernoulli 提出挑战，Newton、Leibniz、Jacob 等五人解答 —— 绝佳的"串联叙事"素材
- **概率论的诞生**：从 Jacob 的《猜度术》到 Daniel 的圣彼得堡悖论
- **师生传承**：Johann → Euler → Lagrange → Fourier ……

## 七、🇫🇷 伯努利与居礼：科学史上两大传奇家族的血脉联结

> *2025年7月，经系谱考证发现*

**居礼家族**是史上获诺贝尔奖最多的家族——两代六人次：

| 获奖者 | 奖项 | 年份 |
|-----------|:----------:|:----:|
| 皮耶·居礼 & 玛丽·居礼 | 物理学奖 | 1903 |
| 玛丽·居礼 | 化学奖 | 1911 |
| 伊雷娜 & 弗雷德里克·约里奥-居礼 | 化学奖 | 1935 |
| 小亨利·拉布伊斯（伊芙之夫） | 和平奖 | 1965 |

如果不以诺贝尔奖为标尺，科学史上唯一能与居礼家族相提并论——甚至犹有过之的——便是**伯努利家族**，三代出了八位杰出数学家与科学家。

### 隐藏的血脉

鲜为人知的是，这两个传奇家族竟然**血脉相连**。经由约翰·伯努利的女儿一脉，可以直接追踪到皮耶·居礼：

```
约翰·伯努利 (1667–1748)
  │
  ├── 尼古拉二世 (1695–1726)
  ├── 丹尼尔·伯努利 (1700–1782)
  ├── 约翰二世·伯努利 (1710–1790)
  │     │
  │     ├── 约翰三世 (1744–1807)
  │     └── 雅各布二世 (1759–1789)
  │           │
  │           └── 娶欧拉孙女为妻  ← 另一重联结！
  │
  └── 安妮·凯瑟琳·伯努利 (女儿)
        │
        └── 嫁 Jean Dollfus
              │
              └── ... (两代) ...
                    │
                    └── Julie Dollfus
                          │
                          └── 嫁 Jean Hofer
                                │
                                └── Augustine Hofer
                                      │
                                      └── 嫁 Paul Curie
                                            │
                                            └── 皮耶·居礼 (1859–1906)
                                                  │
                                                  └── 娶 玛丽·斯克沃多夫斯卡-居礼
```

### 完整世系

1. **约翰·伯努利** (1667–1748) — 数学天才、欧拉之师
2. 其女**安妮·凯瑟琳·伯努利**嫁与 **Jean Dollfus**
3. 曾孙女 **Julie Dollfus** 嫁与 **Jean Hofer**
4. 其女 **Augustine Hofer** 嫁与 **Paul Curie**
5. 其孙：**皮耶·居礼** — 1903年诺贝尔物理学奖得主

> **皮耶·居礼是约翰·伯努利的直系后代。**

### 联姻之力：欧拉也进来了

**雅各布二世·伯努利** (1759–1789) 娶了**欧拉的孙女**为妻——将数学史上最伟大的两个名字，不仅通过学术传承，更以姻亲联结。

### 两大家族对比

| | 伯努利家族 | 居礼家族 |
|---|:---:|:---:|
| **时代** | 17–18 世纪 | 19–20 世纪 |
| **杰出成员** | 8 位数学家 | 5 位诺奖得主（6人次） |
| **核心领域** | 概率论、微积分、流体力学、微分方程 | 放射性、核物理、化学 |
| **诺贝尔奖** | —（诺贝尔奖1901年始设） | 5 项（物理×1，化学×2，和平×1） |
| **跨代跨度** | ~130 年（雅各布 → 雅各布二世） | ~60 年（皮耶&玛丽 → 伊雷娜&伊芙） |

### 一个永恒的疑问

> 这两百年间，是否有一种特定的遗传基因辗转流传——串起了伯努利家族的八位数学家，以及居礼家族的五位诺贝尔奖得主？

科学史上两大最杰出家族的这般重叠，堪称绝无仅有。
