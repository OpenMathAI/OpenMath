## 二、"两大注经者"的叙事逻辑

刘徽注《九章算术》、赵爽注《周髀算经》——两人活跃于同一时代（三国·3世纪），都在前代经典的基础上注入了全新的数学思想。合传的自然叙事线索：

| 维度 | 刘徽 | 赵爽 |
|------|------|------|
| 所注经典 | 《九章算术》(算术百科全书) | 《周髀算经》(天文数学) |
| 核心贡献 | 割圆术·π·极限思想 | 弦图·勾股定理证明 |
| 数学风格 | 算法创新、体系构建 | 几何直觉、视觉证明 |
| 共同点 | 都在经典上做注、都在3世纪活跃、都使用了"图"来辅助证明、都深刻影响了后代(祖冲之·祖暅之) |

## 三、核心贡献表

| 领域 | 贡献 | 人物 |
|------|------|:--:|
| 圆周率 | 割圆术：正 192 边形 → π ≈ 157/50；正 3072 边形 → π ≈ 3.14159（超越阿基米德） | 刘徽 |

| 勾股定理 | 弦图 — 现存最早的勾股定理图示证明（3-4-5 三角形 → 可推广至所有直角三角形） | 赵爽 |
| 线性方程组 | Gaussian 消元法（方 程术）—《九章算术注》中的系统解法，早于 Gauss 约 1500 年 | 刘徽 |

## 五、三幕叙事结构

### 第一幕: 乱世中的两个注经者 (3世纪, 曹魏)
- 三国鼎立——曹操·刘备·孙权的时代
- 刘徽：东汉淄乡侯后裔，选择注《九章算术》
- 赵爽：同样选择注《周髀算经》
- 两人可能互不相识，但做着同样的事——在经典中注入全新的数学思想
- 注经传统：中国知识分子的核心工作模式——"述而不作"，实则"以述为作"

**关键意象**: 乱世中的书房 · 竹简上的数学 · 注经者的孤独

### 第二幕: 割圆术与弦图——两种天才 (核心贡献)
- **刘徽的割圆术**: 
  - 用正多边形逼近圆 → 从 6 边到 192 边到 3072 边
  - π ≈ 157/50 → π ≈ 3927/1250 ≈ 3.14159（超越阿基米德的 3.1408）
  - "割之弥细，所失弥少"——中国极限思想的最清晰表述
  - 此外：Gaussian 消元、负数、Cavalieri 原理先驱
  
- **赵爽的弦图**:
  - 用"弦图"（dissection diagram）证明勾股定理
  - 最简洁的视觉证明：大正方形 = 4×三角形 + 中心小正方形
  - 这是世界数学史上现存最早的勾股定理图示证明
  - 与欧几里得《几何原本》的证明方法完全不同——更直观、更东方

- **两种天才的对比**:
  - 刘徽：算法型天才 — 迭代、逼近、系统化
  - 赵爽：几何直觉型天才 — 一张图胜过千言万语

**关键意象**: 圆与弦 · 逼近的迭代 · 一张图说服所有人

### 第三幕: 留给后人的遗产 (3世纪 → 至今)
- 刘徽的割圆术 → 祖冲之的 π（3.1415926–7）→ 千年世界纪录
- 刘徽的牟合方盖 → 祖暅原理 → 球体积公式
- 刘徽的方 程术 → 千年后的 Gaussian 消元法
- 赵爽的弦图 → 勾股定理的经典证明 → 今天仍在中学课本中
- 《九章算术注》→ 唐代算经十书 → 宋元数学黄金时代的基石
- 两人提出的问题都被后代数学家接力完成——这是一场跨越千年的"数学接力赛"

**关键意象**: 接力棒 · 未竟的问题 · 千年后的回答

## 六、史实陷阱清单

| 陷阱 | 真相 |
|------|------|
| 刘徽生卒年 | ✅ 无确切记录，约活跃于 3 世纪 (225–295 为推测) |
| 赵爽生卒年 | ✅ 无确切记录，仅知 3 世纪活跃 |
| 赵爽 Wikipedia | ⚠️ **无独立英文 Wikipedia 页面！**事迹见于 Zhoubi Suanjing、IM 67118 等页面。中文资料需借助中国数学史著作。 |
| "赵爽" vs "赵君卿" | ✅ 赵爽，又名赵君卿。提示词和 Beamer 中统一使用"赵爽 (Zhao Shuang)" |
| 刘徽 π 精度 | ✅ 192 边形 → 157/50 ≈ 3.14；3072 边形 → 3927/1250 ≈ 3.14159。超越阿基米德的 3.1408 < π < 3.1429 |
| 割圆术与极限 | ✅ "割之弥细……"是《九章算术注》原文（方田章圆田术注），可以作为引语使用 |
| Gaussian 消元 | ✅ 刘徽在《九章算术注》中描述的"方 程术"本质上就是 Gaussian 消元法。注意用词"早于 Gauss 约 1500 年"而非"发明 Gauss 消元" |
| 负数 | ✅ Wikipedia: "could have been the first mathematician to discover and compute with negative numbers; definitely before Brahmagupta" |
| 《海岛算经》 | ✅ 又名《重差》，263 AD，含 9 个测量问题 |
| 牟合方盖 | ✅ 刘徽提出但未能完成，自述"敢不阙疑，以俟能言者" |
| Cavalieri 原理 | ✅ 刘徽使用了等截面原理，Wikipedia 记载 "Cavalieri's principle to find the volume of a cylinder and the intersection of two perpendicular cylinders although this work was only finished by Zu Chongzhi and Zu Gengzhi" |
| 弦图是否赵爽原创 | ⚠️ Zhoubi Suanjing Wikipedia: "there is disagreement as to whether this proof was established by Zhao or merely represented an illustration of a previously understood concept" — 可在 Beamer 中标注为"最早记载/图示"，避免断言"赵爽原创证明" |
| 注疏传统 | ✅ "注"是中国知识分子的核心工作模式之一——在经典文本上添加注释，实则以注为作 |
