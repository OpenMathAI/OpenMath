### 关键时间线:
- 1881: 2月27日生于 Overschie，荷兰新教家庭
- 1904: 与 Korteweg 的首次会面——Korteweg 将成为导师

- 1908: 《逻辑原则的不可靠性》——挑战亚里士多德逻辑的绝对有效性
- 1908, 1912: ICM 特邀报告（罗马、剑桥）——拓扑学新星的崛起
- 1909–1913: 拓扑学的奇迹年——不动点定理、维数不变性、单纯逼近定理、毛球定理、映射度
- 1912: 阿姆斯特丹大学教授。Hilbert 帮助他获得职位——尽管后来成为死敌
- 1912: 荷兰皇家科学院院士
- 1918: 战后开始公开推广直觉主义——排中律不可无限使用
- 1920: Weyl 公开倒向 Brouwer 阵营。Hilbert 震怒："Brouwer 不是革命，而是政变未遂"
- 1920s: Brouwer–Hilbert 论战——数学基础最深的分裂
- 1928: Hilbert 将 Brouwer 从 Mathematische Annalen 编委会驱逐。Einstein 保持中立
- 1930s–1960s: 日益孤立，只讲直觉主义，不再讲拓扑学
- van der Waerden: "他不再相信自己的拓扑学结果——因为从直觉主义角度看它们不正确"
- 1966: 12月2日，85岁，在家门口被车撞死
- 临终前：孤独、偏执（担心破产、受迫害）、被世界遗忘

### ★ 布劳威尔独有的叙事线索

1. **拓扑学的奠基人** — 在 1909–1913 年间，他一口气证明了现代拓扑学的几个基石定理。不动点定理被用于经济学（Nash 均衡）、博弈论、微分方程。维数不变性定理证明了 R^n 和 R^m 在 n≠m 时不同胚——这个"显然"的结论需要天才来证明。

2. **然后他抛弃了它** — van der Waerden 记录道："尽管他最重要的研究贡献在拓扑学，但布劳威尔从未开设拓扑学课程——总是只讲直觉主义的基础。他似乎不再相信自己的拓扑学结果，因为从直觉主义角度看它们不正确。" 他否定了自己最伟大的成就。

3. **Brouwer–Hilbert 论战** — 数学史上最激烈的个人与哲学对决。Brouwer：数学是人类心灵的构造，排中律对无穷不成立。Hilbert："没有人能把我们从 Cantor 为我们创造的天堂中驱逐出去。" Hilbert 利用在 Mathematische Annalen 的权力将 Brouwer 逐出编委会。Einstein 被请来当仲裁——他选择保持中立。

4. **排中律之战** — 直觉主义的核心：不承认排中律对无穷集合有效。"存在一个具有性质 P 的数"——如果你不能构造出它，这个陈述就没有意义。这不仅是数学分歧，是世界观的对立。

5. **Weyl 的叛变** — 1920年，Hilbert 最得意的学生 Hermann Weyl 公开倒向 Brouwer。"Brouwer——这就是革命。" Hilbert 深感背叛。Weyl 后来部分回归了 Hilbert 的纲领，但他对直觉主义的同情从未消失。

6. **《生命、艺术与神秘主义》(1905)** — 24岁的 Brouwer 写出了一本浸透叔本华式悲观主义的小册子。Martin Davis 描述为"drenched in romantic pessimism"。Korteweg 拒绝他论文第二章因为它"充满了神秘主义……这不是数学"。这就是他——一个从一开始就拒绝将数学与人生分开的人。

7. **死在车轮下** — 1966年12月2日，85岁的 Brouwer 在 Blaricum 家门口过马路时被汽车撞死。一个创造了最抽象思想的人，死于最物理的意外。偏执、孤独、担心破产——而实际上他相当富有。

8. **被驱逐的编辑** — Hilbert 利用规则变更将 Brouwer 从 Mathematische Annalen 编委会驱逐。这个行动摧毁了两人的关系。Brouwer 再也没有从中恢复。

## 第 9 步：史实审查（高危陷阱）

| 陷阱 | 要点 |
|------|------|
| **不动点定理年代** | 1910年发表。不是1909，不是1912 |
| **Hilbert 驱逐 Brouwer** | 1928年，通过规则变更。不是因为纳粹同情 |
| **Brouwer 与纳粹** | Fraenkel 指控 Brouwer 有雅利安至上倾向——但没有证据。不要写 Brouwer 是纳粹 |
| **Weyl 倒向 Brouwer** | 1920年。Weyl 是 Hilbert 的学生。不是1918 |
| **Korteweg 拒绝第二章** | 导师拒绝，但 Brouwer 坚持保留。不是整个论文被拒 |
| **《生命、艺术与神秘主义》** | 1905年，24岁。不要写成博士论文 |
| **死于车祸** | 1966年12月2日，Blaricum。在家门口过马路 |
| **Hilbert 引语** | "没有人能把我们从 Cantor 创造的天堂驱逐出去"——Hilbert 1926年。不是对 Brouwer 原文，而是对直觉主义的回应 |
| **Brouwer 引语** | 不存在"数学是人类心灵的构造"精确原文——这是对直觉主义的概括 |
