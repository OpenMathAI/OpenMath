### 人格画像
Mumford 是一个"不满足于一个领域"的数学家。他在代数几何中达到了最高峰（Fields 奖）——然后，在 50 岁时，他转身离开，走进了一个全新的世界：教计算机如何"看"。他不是第一位从纯数学转向应用数学的数学家——但他可能是转型跨度最大的 Fields 奖得主。Zariski 教他代数几何的严格性——他将这种严格性带入了视觉科学。Grenander 的模式理论给了他新的数学语言。他的 Mumford–Shah 泛函至今仍是图像分割的经典方法。他在 80 岁时还在写关于视觉皮层的贝叶斯模型。他的职业生涯回答了这个问题：Fields 奖之后，数学家还能做什么？——答案是：重新开始。

### ★ 叙事主线
1. **模空间之父** — 1961 年博士论文构造了任意亏格曲线的模概形——这是代数几何最核心的结构之一。模空间是现代代数几何的"主战场"——从 Wiles 的费马大定理证明到物理中的弦论，都依赖于 Mumford 奠定的模空间理论。
2. **GIT: 几何不变量理论 (1965)** — 代数群作用于代数簇的商空间何时存在？Mumford 的 GIT 给出了答案：通过稳定性的概念，可以在"足够好"的点集上定义商空间。GIT 是代数几何中最强大的工具之一——从 Donaldson 的 Yang–Mills 理论到表示论中的 quiver 簇，都以 GIT 为基础。
3. **Deligne–Mumford 叠** — 当模空间"不够好"时（奇异点、非正向性），你需要比概形更精细的结构——叠 (stack)。Mumford 和 Deligne 的合作创造了代数叠的语言——这在现代算术几何中无处不在。
4. **正特征曲面的完全分类** — 与 Bombieri 合作，将 Enriques–Kodaira 分类从复数域推广到任意特征的正特征域。这是正特征代数几何的里程碑——后来被 Mori 等人进一步推广到三维。
5. **Grothendieck 的美国使者** — 1963–64 年，Mumford 在哈佛讲授 Grothendieck 的概形语言——这是美国数学界最早系统接触 EGA/SGA 思想的课程之一。他的《代数曲面上的曲线讲义》成为了哈佛研究生必读。
6. **50 岁的重生: Fields → AI** — 1980s，Mumford 做出了数学史上最罕见的决定：在获得 Fields 奖之后，他彻底转换研究方向——从代数几何转向计算机视觉。他相信视觉科学需要数学的严格性——他将代数几何的精确性带入了图像分割和模式识别。
7. **Mumford–Shah 泛函 (1989)** — 这个泛函将图像分割转化为变分问题：寻找分段光滑的最优图像近似。30 多年后，它仍然是图像处理的基础方法——被称为"经典"和"基础性方法"。这证明了：数学直觉即使跨越了领域边界依然强大。
8. **终身的探索者** — 80 岁时还在写视觉皮层的贝叶斯模型。从 Putnam Fellow 到 Fields 奖到 MacArthur "天才"奖到 Wolf 奖——他跨越了纯数学和应用数学。他证明了：数学家的生命力不在于坚持一个领域，而在于不断重新开始。

## ⚠️ 史实陷阱
- **国籍** — **英国出生，英裔美国人。**生于英格兰 Worth，父亲英国人、母亲美国人。幼年移居美国。不要写"美国出生"！
- **GIT 与 Grothendieck** — GIT 是 Grothendieck 框架之外的独立贡献。两者互补——GIT 解决商空间存在性，Grothendieck 的 EGA/SGA 解决概形和上同调基础。

- **Bombieri–Mumford 分类** — 与 Enrico Bombieri（1974 Fields 奖得主）合作。两人都是 Fields 奖得主。
- **曲面的分类** — 正特征域上出现了新的类型（quasi-hyperelliptic, quasi-elliptic），这些在特征 0 时不存在。
- **Putnam Fellow** — 1955 和 1956 两次获得！这是非常罕见的成就。
- **父亲** — William Bryant Mumford 是剑桥数学 Tripos 毕业生。曾任联合国官员。
