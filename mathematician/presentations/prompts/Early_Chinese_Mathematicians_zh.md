## 二、叙事线索："从九章到缉古——中国古代数学的千年演进"

五位数学家的时间跨度约 800 年 (前250–725)，涵盖秦汉—唐代。自然的叙事线索是**中国古代数学从奠基到成熟的发展史**：

| 时代 | 数学家 | 核心贡献 | 历史意义 |
|:--:|------|------|------|
| 秦汉之际 | 张苍 | 整理《九章算术》 | 奠基——古代中国数学的第一本"教科书" |
| 两汉之交 | 刘歆 | π≈3.1547 + 三统历 | 精确化——圆周率和历法的第一次系统研究 |
| 东汉 | 张衡 | π≈√10 + 浑天仪 | 通才之光——数学与天文学、工程的融合 |
| 盛唐 | 一行 | 大衍历 + 子午线实测 | 巅峰·天文数学——全球首次子午线实测 |
| 初唐 | 王孝通 | 25个三次方程数值解 | 算法创新——方程求解达到新高度 |

**叙事弧**：整理经典 (张苍) → 追求精度 (刘歆) → 通才融合 (张衡) → 全球首创 (一行) → 方程突破 (王孝通)

## 四、三幕叙事结构

### 第一幕: 奠基时代 — 张苍与《九章算术》 (前3–前2世纪)
- 秦亡汉兴 — 张苍经历了焚书坑儒后的文化重建
- 《九章算术》成书于秦汉之际，张苍整理定型
- "方田·粟米·衰分·少广·商功·均输·盈不足·方程·勾股" 九章的框架 — 此后 1500 年中国数学的核心教材
- 与刘歆并述：刘歆是第一个尝试精确计算 π (≈3.1547) 的中国人，同时《三统历》奠定历法范式
- 荀子 → 张苍 → 贾谊 — 师承谱系

**关键意象**: 竹简·焚书的余烬中整理出的"九章"·从刘邦帐下走出的数学丞相

### 第二幕: 通才之光 — 张衡与一行的天算融合 (1–8世纪)
- **张衡**: 不是单一的数学家，而是 Archimedes 式的全才
  - π ≈ √10 ≈ 3.1623 (虽精度不如刘歆，但另辟蹊径)
  - 浑天仪 = 水力驱动的天体计算机
  - 候风地动仪 = 世界第一台地震仪 (精确到方位)
  - 月食成因的正确解释
  - 汉赋大家的文学高度

- **一行**: 唐代天文数学的巅峰
  - 《大衍历》的数学创新 — 使用高次差分插值法，精确计算日月运动
  - 世界首次子午线实测 — 组织大规模测量队，从北纬 51° 的铁勒测到北纬 17° 的交州
  - 实测结果 131.3 km/度，与今值 111 km/度的差距主要来自仪器误差
  - 一行 43 岁英年早逝 — "完成使命后离去"的天才

**关键意象**: 浑天如鸡子 → 龙衔地震仪 → 八百里子午线测量队 → 月光是日光的反射

### 第三幕: 方程突破 — 王孝通与三次方程 (7世纪)
- 唐初数学的实用导向 — 土方工程催生了方程求解需求
- 《缉古算经》— 25 个三次方程问题 (外加 2 个二次 + 2 个双重二次)，用"开带从立方"法求解
- 这是世界上最早的**系统性**三次方程数值解法 (早于 Omar Khayyám 几何法，早于 Cardano 公式 900 年)。其思想经伊斯兰世界可能影响了 Fibonacci
- 被收入唐"算经十书" — 也是最难的一部
- 五位数学家的共同遗产：从《九章算术》到《缉古算经》——中国古代数学的算法传统

**关键意象**: 堤坝与沟渠 → 三次方程 → 算筹推演 → 从秦砖汉瓦到盛唐巅峰

## 六、史实陷阱清单

| 陷阱 | 真相 |
|------|------|
| 张苍与《九章》 | ✅ 张苍整理增补《九章》，非原创。原文可能在战国已存在 |
| 刘歆 π | ✅ 3.1547 来自嘉量 (标准量器) 铭文。《隋书·律历志》记载了此值 |
| 张衡 π | ✅ √10 ≈ 3.1623 来自《灵宪》。精度不如刘歆，但体现了独立思考 |
| 地动仪 | ✅ 公元 132 年发明，能指示地震方向。原件已失传，后世有复原模型 |
| 一行·子午线 | ✅ 世界首次子午线实测。注意用"组织"而非"亲自测量"。设 13 个观测站点 |
| 一行·球形认知 | ⚠️ Wikipedia 明确记录一行"did not know the Earth was spherical"——他是从实用角度测量，而非基于球形地球理论 |
| 一行·正切表 | ✅ 《大衍历》中使用了类似正切函数的数值表 |
| 王孝通·三次方程 | ✅ "开带从立方"法解 x³ + px² + qx = N 型方程（25 道 + 2 二次 + 2 双重二次）。比 Cardano (1545) 早约 900 年 |
| 王孝通·Fibonacci | ⚠️ Wikipedia 提及王孝通的三次方程思想经伊斯兰世界可能影响了 Fibonacci（存争议，建议表述为"可能影响"） |
| 张苍长寿 | ✅ 约 101 岁，秦朝活到西汉，历仕四朝 |
| 刘歆结局 | ✅ 因参与反对王莽的政变失败自杀。可简略提及，不宜渲染 |
