## 四、三幕叙事结构

### 第一幕: 从 C 等生到天才 (1930–1960)
- 密歇根大学差点被开除 — B/C 生, 核物理挂科
- 被系主任威胁劝退后开始认真学习
- Bott 的学生 — 1957 年博士
- 芝加哥 → Berkeley → Columbia
- 1959 年球面浸入分类 — 球面翻转

### 第二幕: 打破维度壁垒 (1960–1967)
- 1961 年证明高维 Poincaré 猜想 — 用自索引 Morse 函数
- 1962 年 h-协边定理 — 五维微分拓扑的分类完成
- 1966 年 Fields 奖 + Veblen 奖
- "在里约海滩上完成" — 引发 NSF 调查
- 1966 年莫斯科记者会 — 同时批评美苏越
- 1967 年马蹄映射 — 混沌数学的 DNA

### 第三幕: 数学跨界者 (1967–至今)
- 1970s 数理经济学 — 与诺贝尔奖得主 Debreu 合作
- 1989 BSS 实数计算 — P=NP 在实数域的不同可能性
- 1998 Smale 18 问题 — 21 世纪的 Hilbert 纲领
- 2007 Wolf 奖 — Fields 41 年后的终极认可
- 96 岁依然活跃 — 香港城市大学

## 五、史实陷阱清单

| 陷阱 | 真相 |
|------|------|
| "Smale 证明了 Poincaré 猜想" | ❌ 只证明 n≥5 维度。n=4 → Freedman (1982), n=3 → Perelman (2003) |
| "仍在世" | ✅ 生于 1930-07-15 (96岁) — 不要用过去时 |
| 博士导师 | ✅ Raoul Bott (不是 Morse — Bott 是 Morse 的学生) |
| h-协边年份 | ✅ 1962 (不是 1960 — 1960 是 Morse–Smale 系统) |
| 马蹄映射年份 | ✅ 1967 (不是 1966 Fields 奖同年) |
| "里约海滩" | ✅ 在巴西访问期间完成高维 Poincaré 工作 — 引发国会调查 |
| HUAC | ✅ 因为支持古巴公平对待委员会被传唤 |
| Smale 18 问题年份 | ✅ 1998 (发表在 Mathematical Intelligencer) |
| BSS 机器 | ✅ 1989, 与 Lenore Blum + Michael Shub |
| 国家科学奖章年份 | ✅ 1996 |
