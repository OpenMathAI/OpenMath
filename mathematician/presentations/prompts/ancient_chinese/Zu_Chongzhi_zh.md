## 四、三幕叙事结构

### 第一幕: 少年天才 — 建康城的星与数 (429–461)
- 祖冲之生于建康 (今南京), 刘宋王朝
- 祖父祖昌为大匠卿 (皇家工程总管), 父亲祖朔之为朝官
- 家族天文数学传统 — 从小接触历法与算学
- 少年声名远播, 宋孝武帝送入华林学省 (皇家研究院)
- 南徐州从事 — 开始独立研究工作

**关键意象**：建康 → 皇家学府 → 用算筹推演星空的少年 → 中国式天才的古典形象

### 第二幕: π的征服者 — 娄县县令的千年一算 (461–500)
- 464 调任娄县, 开始编制《大明历》+ 计算 π
- 使用刘徽割圆术, 以正 12288(= 213×3) 边形逼近圆
- **仅用算筹 (木棍)** — 没有纸笔、没有算盘、没有代数符号
- π 精确到小数点后 7 位: 3.1415926 < π < 3.1415927
- 密率 355/113 — "祖率" — 日本数学史家三上义夫极力主张以祖冲之命名
- 《大明历》: 一回归年 365.24281481 天 (与现代值相差不到 50 秒!)
- 发明创造: 千里船 (桨轮船)、水碓磨、重造指南车 (差速齿轮)
- 《缀术》: 与祖暅之合著 — 唐初"算经十书"之一, 也是最难的一部
- 《大明历》未被立时颁行 — 保守派戴法兴反对; 祖冲之撰《驳议》力辩

**关键意象**: 算筹 → 12288 边形 → 黑暗中的计算 → 千年后人们才知道他算得有多准

### 第三幕: 父子传承与千年之后 (500–至今)
- 500 年祖冲之逝世, 510 年《大明历》终获颁行
- 祖暅之继承父业 — 证明球体积公式, 提出"祖暅原理"
- 《缀术》随宋代战乱佚失 — 中国数学史上最大的损失之一
- 千年之后: 月球环形山、小行星以他命名
- 今日: 祖冲之号量子计算机、ZUC 流密码 — 名字在数字时代重生
- 尾声: 一个 5 世纪中国人的 π 计算, 精度超过此后千年间任何文明

**关键意象**: 佚失的《缀术》→ 月球上的名字 → 量子时代的复活 → 文明传承的厚度

## 五、史实陷阱清单

| 陷阱 | 真相 |
|------|------|
| 朝代 | ✅ 刘宋 → 南齐 (南北朝), 不是"南朝宋"或简单的"宋" |
| 出生地 | ✅ 建康 = 今南京, 祖籍范阳遒县 = 今河北保定涞水 |
| 割圆术方法 | ✅ 使用刘徽的方法, 而非独立发明; 正 12288 边形 (= 213×3) 而非 24576 边形 (不同来源有争议) |
| π 精度 | ✅ 两个近似值: 密率 355/113 + 约率 22/7; 上限 3.1415927, 下限 3.1415926 |
| 算筹 | ✅ 主要计算工具是算筹 (木棍), 不是算盘 (算盘在宋代才普及) |
| 大明历 | ✅ 编成于 465 年, 但直到 510 年 (死后十年) 才正式颁行 — 因保守派戴法兴反对 |
| 指南车 | ✅ 重造而非发明; 原为马钧 (三国时期) 所创, 后失传 |
| 《缀术》 | ✅ 与子祖暅之合著; 唐代算经十书之一; 宋代已佚失 — 今人只能通过其他著作的引用了解其内容 |
| 祖暅原理 | ✅ "幂势既同, 则积不容异" — 等价于 Cavalieri 原理; 但中国古代数学缺乏严格证明体系, 更多是直觉+案例 |
| 球体积公式 | ✅ 刘徽开创牟合方盖思路但未完成 → 祖冲之/祖暅之父子完成 |
| 祖暅之名字 | ✅ 正名"祖暅之", 也常简写为"祖暅"; 字景烁 |
| 三上义夫评价 | ✅ 日本数学史家 Yoshio Mikami 主张将 355/113 命名为"祖率"(Zu's fraction) |
