### 关键时间线（15–20 个节点）：

- 1968: Park School of Baltimore 毕业
- 1960s 末: 在 *The New Republic* 和 *The Nation* 发表政论文章，梦想成为记者

- 1997–: 在 Maldacena 的 AdS/CFT 对应基础上做奠基性工作
- 1999: 与 Pierre Deligne 等人合编 *Quantum Fields and Strings: A Course for Mathematicians*

- 2012: 获基础物理学突破奖
- 2014: 获京都奖

### 人格特质线索：
- 本科读历史、梦想当记者，最后却成为"最聪明的在世物理学家"—— 一段罕见的跨界传奇
- Atiyah 在菲尔兹奖书面致辞中评价："他无疑是物理学家，但他的数学造诣令少数数学家望尘莫及；他一次又一次以物理洞察带来新的深刻数学定理。"
- 1990 年一次宇宙学会议的非正式投票中，Witten 被提名"最聪明的在世物理学家"次数最多
- 他的工作方式独树一帜：**用物理直觉"猜"出数学定理，再由数学家去严格化**
- 他的 TQFT 工作基于数学上不严格的费曼路径积分，却催生了 Reshetikhin–Turaev 不变量等严格数学理论
- 低调而深思，几乎不接受媒体专访，但学术影响力遍及理论物理与纯数学两个世界

### ★ Witten 独有的叙事线索

1. **"历史系学生"到"最聪明的物理学家"** — Witten 本科主修历史、辅修语言学，曾为 McGovern 总统竞选工作、给政治杂志写稿。这段从人文到物理的跨界之路，是他最独特、最动人的生平故事。
2. **第一位获菲尔兹奖的物理学家** — 1990 年菲尔兹奖颁给一位物理学家，这在数学史上绝无仅有。Atiyah 的致辞明确指出：他"用物理洞察力一次又一次给数学界带来惊喜"。
3. **物理直觉驱动数学发现的方法论** — Witten 的工作常常基于物理直觉（甚至数学上不严格的路径积分），却引出深刻的数学定理。TQFT、Seiberg–Witten 不变量、Witten 猜想都是"物理猜、数学证"的经典案例。
4. **M-theory 的统一视野** — 1995 年，五种看似矛盾的弦论被 Witten 揭示为同一个理论的五个极限。这是理论物理最具想象力的一次统一。
5. **"给数学家的量子场论"** — 1996–1997 年他与 Deligne 等人在 IAS 举办面向数学家的量子场论研讨年，结集出版《Quantum Fields and Strings》，主动把物理工具输送给数学界。
6. **弦论的第二次革命** — Witten 的 M-theory 提案直接引发了 1990s 中期的第二次超弦革命，改变了整个高能理论物理的方向。
7. **"最聪明的在世物理学家"** — 1990 年一次非正式投票的称号（需加"据传/非正式"），反映同行对其智识的高度认可。

## 第 9 步：史实审查

### Witten 特有的史实陷阱（★ 高危）

| 陷阱类型 | 高危点 |
|---------|--------|
| **"第一位获菲尔兹奖的物理学家"** | 这是正确的（1990），但要表述准确："第一位也是迄今唯一以物理学家身份获菲尔兹奖的人"。不要写成"第一位非数学家获菲尔兹奖"（菲尔兹奖不限定学科，且此前已有其他交叉领域获奖者）。 |
| **正能定理的归属** | 正能定理的原始证明是 Richard Schoen 与丘成桐（变分法，1979–1981）。Witten 的贡献是 1981 年用超引力方法给出**更简洁的证明**。不要写"他首先证明了正能定理"。 |
| **TQFT 的数学严格性** | Witten 的 TQFT 工作基于费曼路径积分，数学上**不严格**。数学家后来将其严格化（Reshetikhin–Turaev 不变量等）。不要写"他严格证明了……"，应写"他的物理构想后来被数学家严格化"。 |
| **M-theory 的"M"含义** | Witten 本人未明确"M"代表什么（membrane、matrix、magic、mystery 等均有说法）。不要擅自解释"M"的含义。 |
| **"最聪明的在世物理学家"** | 这是 1990 年一次宇宙学会议的非正式投票，不是正式荣誉。必须加"据传/非正式投票"限定。 |
| **博士导师** | 主要导师是 David Gross（论文导师）。infobox 同时列出 Michael Atiyah，但 Atiyah 更多是学术指导而非论文导师。表述为"导师 David Gross（另有 Atiyah 的指导）"。 |
| **本科专业** | Witten 本科主修**历史**、辅修语言学，不是数学或物理。这是重要叙事点，务必准确。 |
| **弦论教材** | *Superstring Theory* 是 Green、Schwarz、Witten **三人合著**，不要只写"Witten 的教材"。 |
| **Seiberg–Witten 合作** | Seiberg–Witten 理论是**与 Nathan Seiberg 合作**，不要遗漏合作者。 |
| **AdS/CFT 的归属** | AdS/CFT 对应是 Juan Maldacena 1997 年提出的。Witten 做的是**后续奠基性工作**，不要写"Witten 提出 AdS/CFT"。 |
