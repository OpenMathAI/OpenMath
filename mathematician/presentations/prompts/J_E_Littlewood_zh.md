### 人格特质:
- 极长寿——92岁，晚年仍写论文
- Landau 不相信 Littlewood 的存在——以为是 Hardy 的笔名，专程从德国飞到英国来"验证"，结果到剑桥只见到了 Hardy 没见到 Littlewood，于是"证实"了自己的猜想

### ★ Littlewood 独有的叙事线索

1. **"第三个数学家"** — Bohr 名言。"当今只有三个真正伟大的英国数学家：Hardy、Littlewood 和 Hardy–Littlewood。"——这是最准确的描述，因为 Littlewood 几乎无法脱离 Hardy 来叙述。他是合作中的"想法提供者"。

2. **Landau 的虚构猜想** — 德国数学家 Landau 怀疑 "Littlewood" 是 Hardy 为次等作品用的笔名。他从德国专程来到剑桥，在 Trinity 见到了很多 Hardy 却没见到 Littlewood，于是宣布"我的猜想被证实了"。Norbert Wiener 也被传有类似经历（他激烈否认）。

3. **π(x) − Li(x) 的惊天振荡** — 1914年，所有人都相信数值证据：π(x) < Li(x) 对所有 x 成立（已算到极大范围）。Littlewood 证明了这个差会变号——而且无穷多次。第一个变号点在哪里？他的学生 Skewes 给出了一个天文学上界：Skewes 数 ~ 10^(10^(10^34))。这就是解析数论最著名的"不可计算"结果。

4. **炮弹与雷达** — WWI 在皇家要塞炮兵做弹道学。1930s末与 Mary Cartwright 独立研究雷达需要的非线性微分方程，这后来成为动力系统和混沌理论的先驱。纯数学家为国家做"有用"的事——而 Hardy 一辈子都没克服这个矛盾。

5. **南非的童年** — 7-15岁在南非 Wynberg。父亲是校长。这段离开英格兰的经历让他成为一个"旁观者"，与封闭的英国学术社会保持着微妙的距离。

6. **Barnes 的荒唐建议** — 博士导师 Barnes 建议他："试试证明黎曼假设。" Littlewood 没成功——但他证明了如果 RH 成立，素数定理就成立，并得到了误差项。这是英国数学落后的体现：这个联系在欧洲大陆早已为人所知。

7. **Miscellany** — 《一个数学家的杂集》是他唯一的非技术著作。充满了数学八卦：关于 Hardy、Ramanujan、Russell、Wittgenstein 的趣闻。它就像 Victorian 时代的 whispering gallery——低声说出数学殿堂里最大的秘密。新版由 Bollobás 编辑，改名《Littlewood's Miscellany》。

8. **码头上的 n, n alpha, n beta** — 1941年 Donald Spencer 即将登船返美参加战争。Littlewood 赶到码头，大喊："n, n alpha, n beta!"——这是 Littlewood 猜想的参数。在战争的阴影下，他关心的仍然是数学。

9. **活到92岁** — 他是这批数学家中最长寿的之一。退休后继续发表论文直到80多岁。他的职业生涯跨越了两次世界大战、从维多利亚时代到太空时代。

## 第 9 步：史实审查（高危陷阱）

| 陷阱 | 要点 |
|------|------|
| **Hardy 评价 Littlewood** | Hardy=25, Littlewood=30——L 高 5 分。不要写成 L 低于 H |
| **Landau 故事** | Landau 确实去了剑桥。但 Wiener 版本——他否认了。不要混淆 |
| **"Hardy–Littlewood" 说法来源** | Harald Bohr，1947年讲座 |
| **π(x) − Li(x) 变号** | 第一个变号点在 Skewes 数处，远大于任何可计算范围。不要写成"Littlewood 算出来了" |
| **RH 作为博士课题** | Barnes 建议。Littlewood 没证明。证明了 RH ⇒ PNT |
| **Mary Cartwright** | 合作关系，不是导师/学生。两人独立工作 |
| **Rouse Ball 教授** | 1928 年到 1950 年退休 |
| **Miscellany** | 1953年第一版，1986年 Bollobás 新版改名《Littlewood's Miscellany》 |
| **南非** | 1892–1900，精确来说 8 年（不是 "7-15岁" 精确，但大致） |
