## 第 0 步：下载 Wikipedia 页面并校验

- **生卒日期**：1877-02-07 ~ 1947-12-01，享年 70 岁
- **国籍**：英国
- **出生地**：Cranleigh, Surrey, England
- **博士导师**：Augustus Edward Hough Love（剑桥大学）
- **博士论文**：1903，积分方程
- **主要任职**：剑桥大学三一学院 (1900–1919)，牛津大学 (1919–1931)，重返剑桥 (1931–1942)
- **关键荣誉**：皇家学会院士 (1910)、De Morgan 奖章 (1929)、Sylvester 奖章 (1940)、Copley 奖章 (1947)
- **重要合作者**：J.E. Littlewood（35 年合作）、Srinivasa Ramanujan（发现的印度天才）、Wilhelm Weinberg（Hardy–Weinberg 定律）

### 关键时间线（15–20 个节点）：
- 1877: 生于英格兰萨里郡教师家庭
- 1896: 进入剑桥大学三一学院
- 1900: 当选三一学院 Fellow
- 1903: 获博士学位
- 1908: 发表《纯粹数学教程》(A Course of Pure Mathematics)——改革英国数学教育
- 1911: 开始与 Littlewood 长达 35 年的传奇合作
- 1913: 收到 Ramanujan 的来信——发现印度的数学天才
- 1914–1919: 一战期间，Ramanujan 在剑桥
- 1919: 因 Russell 事件（反对解雇反战的 Bertrand Russell）离开剑桥去牛津
- 1920: Ramanujan 在印度去世
- 1931: 重返剑桥
- 1940: 出版《一位数学家的辩白》(A Mathematician's Apology)
- 1947: 自杀未遂后病逝，享年 70 岁

### 人格特质：
- 纯粹的数学纯粹主义者："我从未做过任何'有用的'事——这是我人生的骄傲。"
- 板球狂热者——用板球评分系统评价数学定理
- 与 Littlewood 的"公理式合作"：四条公理定义了他们的合作方式
- 对 Ramanujan 的伯乐之恩是他一生最自豪的事

## 核心数学贡献

| 领域 | 贡献 | 年代 |
|------|------|:--:|
| 解析数论 | Hardy–Littlewood 圆法 | 1920s |
| 数论 | Hardy–Ramanujan 渐进公式（分拆函数） | 1918 |
| 分析 | Hardy–Littlewood 极大函数 | 1930 |
| 不等式 | Hardy 不等式、Hardy–Littlewood–Pólya 不等式 | 1920s–1934 |
| 遗传学 | Hardy–Weinberg 定律 | 1908 |

### ★ 叙事线索
1. **Ramanujan 的伯乐** — 1913 年收到一封来自印度小职员的信，Hardy 认出了其中的天才
2. **Littlewood 的传奇合作** — 35 年，100+ 篇论文，四条合作公理
3. **英国分析的救世主** — 在 Hardy 之前，英国数学落后于欧陆。他的《纯粹数学教程》是变革的起点
4. **《一位数学家的辩白》** — 一个临死之人的数学哲学自白。美丽、哀伤、纯粹
5. **纯粹性的代价** — 晚年抑郁，认为自己的创造力已耗尽

### ⚠️ 史实陷阱
| 陷阱 | 细节 |
|------|------|
| Hardy–Weinberg | Hardy 不是唯一的发现者。Weinberg 独立发现。不要暗示 Hardy 是"唯一"发现者 |
| Ramanujan 的"发现" | Ramanujan 先给其他英国数学家写信（被忽视）后才联系 Hardy |
| 与 Russell 的关系 | 他离开剑桥到牛津是出于对 Russell 的忠诚（一战期间被解雇），不是学术竞争 |
| "1729" 出租车数 | 这是 Hardy 去医院探望 Ramanujan 时的轶事——真实但经常被浪漫化 |
| 自杀未遂 | Hardy 1947 年在剑桥宿舍中自杀未遂后几天去世 |

### ⚠️ 终审高危点
| 高危点 | 检查方法 |
|---------|---------|
| Ramanujan 来信年份 | page.md 搜索 "1913" |
| 合作公理 | 四条：他们之间不需要"一致同意"即可给对方署名 |
| 板球评分 | 用板球术语评价数学家——他的个人癖好 |
| 死亡情境 | 自杀未遂→几天后去世，不要写成"直接自杀" |
