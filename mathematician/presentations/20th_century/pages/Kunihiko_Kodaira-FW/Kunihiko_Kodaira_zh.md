## 四、三幕叙事结构

### 第一幕: 战争孤岛上的 Hodge 理论 (1915–1949)
- 东京出生 — 数学+物理双学位
- 二战期间 — 在完全孤立中自学 Hodge 理论
- 1949 博士 + 受 Weyl 邀请赴 IAS Princeton
- 从东京的废墟到普林斯顿的学术圣殿

**关键意象**: 战争中的东京 → 孤独的自学 → Weyl 的邀请函 → 飞向新世界

### 第二幕: 复几何的体系构建 (1949–1961)
- IAS + Princeton — 12 年的黄金岁月
- 小平消没定理、小平嵌入定理 — 复几何的理论基石
- 与 Spencer 合作 — 创立形变理论 (Grothendieck 的概形理论受其影响)
- 1954 年 Fields 奖 — 第一位日本获奖者
- 受到 Hirzebruch 等人的高度评价

**关键意象**: Hodge → 消没定理 → 嵌入定理 → 形变理论 → Fields 奖的加冕

### 第三幕: 代数曲面的完全分类 (1961–1997)
- 完成 Enriques–小平分类 — 七种曲面的完整图谱
- K3 曲面 — 第三种曲面类型以他命名
- 小平维数 — 成为 Mori 的极小模型纲领的核心工具
- Wolf Prize 的终身成就认可
- 1997 年甲府逝世

**关键意象**: 曲面分类的完成者 → K3 → 小平维数 → Wolf Prize → 日本代数几何之父

## 五、Fields Medal 1954 — 首位日本得主

> 1954 年阿姆斯特丹 ICM — 小平邦彦与 **Jean-Pierre Serre** 同获 Fields 奖。这是 Fields 奖历史上第一次授予亚洲数学家。授奖理由: 他在调和积分、复流形和代数几何方面的工作。

- **意义**: 小平的 Fields 奖标志着日本数学从追赶欧洲到进入世界一流的历史转折。
- **师承链**: David Hilbert → 高木貞治 → 弥永昌吉 → **小平邦彦** → 飯高茂/宮岡洋一—日本数学四代人的接力。
