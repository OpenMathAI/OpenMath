## 四、三幕叙事结构

### 第一幕: 从岐阜乡村到哥廷根 — Hilbert 的日本学生 (1875–1914)
- 岐阜乡村少年 — 中学读英文数学书自学
- 东京帝国大学 — 当时日本唯一的大学
- 赴哥廷根 — 师从 David Hilbert
- 1903 年左右获博士学位

**关键意象**: 明治时代的日本 → 哥廷根的数学圣地 → Hilbert 的东方弟子

### 第二幕: 孤岛上的天才 — 类域论的诞生 (1914–1926)
- 一战爆发 — 与欧洲数学界完全隔绝
- 在孤立中独立发展类域论 — 证明 **Takagi 存在定理**
- 1920 年 ICM Strasbourg — 宣讲，但几乎无人听懂
- 1922 年 Emil Artin 首先发现其价值
- 1925–1926 年 Hasse 的 *Klassenkörperbericht* — 高木的国际地位正式确立

**关键意象**: 隔绝的孤岛 → 孤独的证明 → 迟到的认可 → 世界级数论大师

### 第三幕: 日本数学之父 (1926–1960)
- 1932 ICM 副主席
- 1936 首届 Fields 奖评选委员
- 二战参与密码工作
- 编写教科书 — 培养日本现代数学的几代人
- 文化勋章、文化功労者
- 1960 年 84 岁逝世

**关键意象**: 从被孤立的数学家 → Fields 奖的裁判者 → 日本数学的灵魂

## 五、Takagi 存在定理 — 一个被历史埋没又重见天日的定理

> Takagi 证明了: 对于任何代数数域 K，K 的每个有限 Abel 扩张对应一个 K 的理想类群的商群，反之亦然。这是一个**一一对应**——将数域的 Galois 理论与理想类群完美统一。

- **1914–1918**: 一战期间独立证明（与欧洲数学界完全隔绝）
- **1920**: ICM Strasbourg 宣讲 — 几乎没有数学家能理解
- **1922**: Emil Artin 首先认识到其重要性
- **1925–26**: Hasse 的 *Klassenkörperbericht* — 将高木的工作系统介绍给欧洲数学界
- **从此**: 高木被公认为类域论的创立者——他完成的不仅仅是"证明了一个定理"，而是建立了类域论这整个体系

> 这是 20 世纪纯数学最伟大的成就之一。Hasse 本人从事类域论研究——但真正完成整个体系的，是高木贞治。

## 六、史实陷阱清单

| 陷阱 | 真相 |
|------|------|
| 名字顺序 | ✅ 日文名: 高木 貞治 (Takagi Teiji)。Takagi 是姓，Teiji 是名。国际引用: Teiji Takagi 或 T. Takagi |
| 类域论创立者 | ✅ 他是类域论的创立者 — 不是 Hasse。Hasse 是将高木的工作系统整理推广的人 |
| 导师 | ✅ David Hilbert — 哥廷根时代。不是 Göttingen 任何其他数学家 |
| Takagi 存在定理年份 | ✅ 1914–1918 独立证明，1920 年发表 |
| 第一次世界大战 | ✅ 一战是他完成类域论的关键时期 — 被隔绝反而促成了独立突破 |
| 1920 ICM | ✅ Strasbourg — 当时德国数学家被排除在外，高木的工作未获即时认可 |
| 1926 Klassenkörperbericht | ✅ Hasse 的著作是德国数学界承认高木工作的转折点 |
| Takagi 曲线 | ✅ 又名 Blancmange 曲线。被归为"Takagi 曲线"是因为高木首先研究了它 — 而非他发明了它（首次由 van der Waerden 1930 年描述，但高木早在1903年已研究） |
| 逝世日期 | ⚠️ 2月28日或29日存在歧义（Wikidata 给出了两个日期），以 1960-02-28 为准 |
| Purple 密码机 | ✅ 参与日本帝国密码系统的数学工作 |
